    First run · the short version
    
    
    What this console can and cannot do
    
    
    It sits between an application and its model. Text going in or out is checked against the rules for its page; the decision is allowed or blocked. This console is the window into that.
    
    
    
      
    Read the policy
    Per-page patterns, keywords, limits and which checks run.
    
      
    Test real text
    The bench sends an actual request; the verdict is the server's.
    
      
    Know who can do what
    Admin, developer, viewer — enforced by the server, not by hidden buttons.
    
      
    Watch the system
    Counters, integrity and risk — including when they report a problem.
    
    
    
    
    
      
    What it cannot do — read before trusting a green tick
    
      
      
        
    • A pass is not a guarantee. It means no enabled rule matched.
      • 
        
    • The rules are regular expressions. Unseen formats and encoded payloads can slip past.
      • 
        
    • Credential detection is a short list. Not every key format is covered.
      • 
        
    • Shell commands can launder file access. Text passed to a subprocess never touches path rules.
      • 
        
    • Nothing is computed here. If the server is unreachable the result is unknown, never safe.
